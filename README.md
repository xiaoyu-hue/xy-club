# 俱乐部官网模板 · XY俱乐部

一套**可复用的俱乐部官网模板**：液态玻璃（Liquid Glass）视觉体系 + 微交互，官网与后台管理系统一体，内容全部由数据驱动 —— 换俱乐部只需改内容、换主题，无需改代码。

> English version: [README_EN.md](./README_EN.md)

## ✨ 特性

**视觉**
- 液态玻璃体系：高斯模糊玻璃 + 光标高光追踪 + 流光扫过
- 4 套主题配色一键切换：极光紫 / 深海蓝 / 晨雾白（浅色）/ 落日金
- 液态流光背景，深浅主题均保持玻璃质感

**微交互（8 处）**
- 玻璃卡片光标高光追踪、卡片 3D 微倾斜、按钮点击涟漪
- 首屏数字滚动动画、顶部滚动进度条、返回顶部按钮
- 导航当前板块高亮、滚动错落渐显 + 背景视差
- 移动端自动降级（倾斜/高光仅在鼠标设备生效）

**内容与后台**
- 7 种板块类型：价目列表 / 卡片网格 / 客户评价 / 常见问答 / 须知列表 / 图片集 / 图文段落
- 每个板块可编辑、↑↓ 排序、👁 显示隐藏、删除，随时新增板块
- 网站设置：名称、Logo、首屏文案、公告、联系方式、客服二维码、页脚
- 图片上传（≤8MB）、修改管理密码
- **模板复用**：配置导出 / 导入 JSON、一键恢复默认内容

## 📁 目录结构

```
xy-club/
├── server.js            # Express 服务：静态托管 + REST API + 登录鉴权 + 图片上传
├── defaults.js          # 模板默认内容（改这里可改「出厂配置」）
├── package.json
├── data/
│   └── db.json          # 运行时内容数据（自动生成，已 gitignore）
└── public/
    ├── index.html       # 官网前端
    ├── admin.html       # 后台管理系统
    ├── uploads/         # 后台上传的图片
    ├── css/             # style.css（官网）· admin.css（后台）
    └── js/              # main.js（官网渲染+微交互）· admin.js（后台逻辑）
```

## 🚀 快速开始

```bash
pnpm install      # 或 npm install
node server.js    # 默认 http://localhost:3000
```

- 官网：<http://localhost:3000>
- 后台：<http://localhost:3000/admin>
- **默认管理密码：`xy888888`** —— 登录后请立即在「网站设置 → 修改管理密码」中更换
- 端口可通过环境变量指定：`PORT=8080 node server.js`（已绑定 `0.0.0.0`，可直接部署）

> 首次启动会自动由 `defaults.js` 生成 `data/db.json`；删除该文件即可恢复出厂内容。

## 🔁 复用模板（给另一个俱乐部用）

1. 在原站点后台「网站设置 → ⬇️ 导出配置」得到整站 JSON
2. 部署一份新站点 → 后台「⬆️ 导入配置」载入该 JSON
3. 改这四处即可：网站名称 / Logo、首屏文案、联系方式（微信·QQ·二维码）、板块内容
4. 按需在「主题配色」切换风格，点「保存修改」即刻生效

## 📦 部署

单端口 HTTP 应用，无需数据库，任何支持 Node.js 的平台均可：

```bash
PORT=8080 node server.js     # 平台会注入 PORT，服务已监听 0.0.0.0
```

静态资源与 API 同端口提供；上传的图片存于 `public/uploads/`。

## 💾 数据与备份

- 所有内容存于 `data/db.json`（重启不丢失，已排除在版本控制外，因为含管理密码）
- 建议定期用后台「导出配置」备份 JSON
- 忘记密码：编辑 `data/db.json` 的 `settings.adminPassword` 字段后重启
