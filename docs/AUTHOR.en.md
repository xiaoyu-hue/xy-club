# About the Author

**xiaoyu-hue** — author and maintainer of the XY Club Website Template.

## In one line

Not a coder, but believes people without code skills deserve a good-looking, easy-to-edit, easy-to-deploy website. Development, testing, and docs are done with AI Agent collaboration.

## Why this project

Most club websites are either ugly, uneditable, or hard to deploy. This project proves one thing: **zero-build, zero-dependency, single-JSON-file can still deliver a Liquid Glass look, micro-interactions, a visual admin, and a reusable template that also works as pure static hosting.**

## How I work

- The author sets direction and makes the call; AI Agents implement (rules in `AGENTS.md`).
- Big moves pass the three decision questions in `DECISION_REVIEW.md`; major decisions become `docs/adr/`.
- Before each release, the sync checklist in `DOC_SYNC.md` keeps docs and code consistent.

## Design stance

- Visual: Liquid Glass + restrained motion, respecting `prefers-reduced-motion`.
- Engineering: no dependency if avoidable; no build if avoidable; let people edit directly, no detours.
- Docs: Chinese as baseline, English mirrored (`.en.md`) in sync; decisions and changes are recorded.
