## 一句话

不懂代码，但相信"不懂代码的人也该拥有好看、好改、好部署的官网"。靠 AI Agent 协作完成开发、测试与文档。

## 为什么做这个项目

市面上多数俱乐部官网要么丑、要么改不动、要么部署麻烦。本项目想证明一件事：**零构建、零依赖、单 JSON 文件，也能做出 Liquid Glass 质感、带微交互、后台可视化、还能纯静态托管的可复用模板。**

## 协作方式

- 作者定方向与拍板，AI Agent 落地实现（规则见 `AGENTS.md`）。
- 大事先过 `DECISION_REVIEW.md` 的决策三问，重大决定沉淀为 `docs/adr/`。
- 每次发版前走 `DOC_SYNC.md` 的同步清单，保证文档与代码一致。

## 设计取向

- 视觉：液态玻璃 + 克制的动效，尊重 `prefers-reduced-motion`。
- 工程：能不引入依赖就不引入；能不构建就不构建；能让人直接改就不绕弯。
- 文档：中文为基准，英文镜像（`.en.md`）同步；决策与变更都要留痕。
