## 📊 项目现状分析

### 技术栈
| 层级 | 技术 | 说明 |
|------|------|------|
| 后端 | Node.js + Express | 单进程，JSON 存储 |
| 前端 | Vanilla JS + CSS | 零框架，零构建 |
| 测试 | Node.js --test | 123项单元测试 |
| E2E | Playwright | 可选，浏览器测试 |
| 部署 | Render / GitHub Pages | 双路线支持 |

### 核心特性
- ✅ 8种板块类型（services/cards/testimonials/faq/notice/text/custom/gallery）
- ✅ 4套主题（aurora/ocean/mist/sunset）
- ✅ 液态玻璃视觉风格
- ✅ 8处微交互（光标高光、卡片倾斜、点击涟漪等）
- ✅ 后台管理（登录/编辑/上传）
- ✅ 静态回退（GitHub Pages 支持）
- ✅ 安全加固（scrypt密码/CSRF/输入验证）
- ✅ 图片上传（白名单+限大小）

### 已知局限
- ❌ 单管理员（无多用户/角色）
- ❌ 单进程（无水平扩展）
- ❌ 内存会话（重启丢失）
- ❌ 无数据库（JSON文件存储）

### Phase 1: 功能增强（预计 7-10 天）

#### 1.1 多语言支持（国际化）

**需求**: 支持中英文切换，为后续国际化做准备。

**实现方案**:
```javascript
// i18n.js - 简单的多语言模块
const translations = {
  zh: { siteName: 'XY俱乐部', login: '登录' },
  en: { siteName: 'XY Club', login: 'Login' }
};

function t(key, lang = 'zh') {
  return translations[lang][key] || key;
}
```

**改动点**:
- 新增 `public/js/i18n.js`
- 修改 `admin.js` 添加语言切换
- 更新所有文本为 i18n 键

**预估**: 2天

---

#### 1.2 内容版本历史

**需求**: 记录每次内容修改，支持回滚。

**实现方案**:
```javascript
// 在 db.json 中添加 _history 字段
{
  "settings": { ... },
  "sections": [ ... ],
  "_history": [
    { "timestamp": "2026-09-29", "action": "update", "user": "admin" }
  ]
}
```

**改动点**:
- `server.js` 修改内容写入逻辑
- `admin.js` 添加历史查看界面
- 数据库 schema 变更

**预估**: 3天

---

#### 1.3 备份与恢复

**实现方案**:

**改动点**:
- `server.js` 添加备份路由
- `admin.js` 添加备份界面
- `tests/backup.test.js` 新增测试

**预估**: 2天

## 📝 开发纪律

1. **测试先行**: 新功能必须先写测试
2. **文档同步**: 功能改动必须同步文档
3. **版本一致**: Git Tag = 代码版本 = 文档版本
4. **安全优先**: 涉及鉴权/输入/存储的改动必须审查
5. **向后兼容**: 不破坏现有功能

```bash
cd xy-club
pnpm install
npm test
node server.js
```

### Docker 部署
```bash
docker-compose up -d
```
