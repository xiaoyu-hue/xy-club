## 🔧 技术要点

### 1. 变量命名保持 xy-club 规范

```css
/* xy-club 特有变量 */
--bg-a, --bg-b     /* 背景渐变 */
--ink              /* 主文字色 */
--muted, --faint   /* 次要文字色 */
--gold-1/2/3      /* 金色变量（所有主题保留） */
--b1/2/3          /* 光斑 */
--spot             /* 光标高光 */
--sheen            /* 光泽效果 */
```

### 2. 亮色主题适配

**光斑透明度降低**（避免刺眼）:
```css
/* 暗色主题 sunset */
--b1: rgba(244, 114, 182, 0.4);

/* 亮色主题 neutral_morning */
--b1: rgba(147, 197, 253, 0.2);  /* 降低 50% */
```

**玻璃透明度提高**（增强玻璃效果）:
```css
/* 暗色主题 sunset */
--glass-1: rgba(255, 255, 255, 0.11);

/* 亮色主题 neutral_morning */
--glass-1: rgba(255, 255, 255, 0.75);  /* 提高 7 倍 */
```

### 3. 与 xy-intro-card 的区别

| 对比项 | xy-intro-card | xy-club |
|--------|---------------|---------|
| 选择器 | `:root` + JS | `html[data-theme]` |
| 变量命名 | `--bg`, `--text` | `--bg-a`, `--ink` |
| 特有变量 | 无 | `--gold-*`, `--spot`, `--sheen` |
| 主题数量 | 8 套 | 8 套（同步） |
